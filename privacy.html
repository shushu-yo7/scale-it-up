Privacy Policy – Scale It Up Uploader

Last updated: November 8, 2026

What this tool is

Scale It Up Uploader is a private tool used only by the owner of the YouTube channel Scale It Up. It uploads the channel's own videos and sets their titles, descriptions and publish times.

Data it uses

With the owner's permission, the tool uses the YouTube Data API to upload videos to the owner's channel and to read basic channel information (the channel name) to confirm it is connected to the right channel. It does not read comments, subscribers, viewing history or any other user's data.

Where data is stored

The access token Google issues is stored only on the owner's own computer. No data is sent to any server other than Google's.

Sharing

No data is sold, shared with or transferred to third parties. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Google Account permissions.

Contact

Questions can be sent through the Scale It Up channel page.
